# Ícone do Aplicativo

Coloque aqui o arquivo `app_icon.png` com o logo do Simagestor App.

**Especificações recomendadas:**
- Formato: PNG
- Tamanho recomendado: 1024x1024 pixels
- Fundo: transparente ou sólido (será usado o círculo teal como fundo adaptativo)

Depois de adicionar o arquivo, execute:
```bash
flutter pub run flutter_launcher_icons
```
